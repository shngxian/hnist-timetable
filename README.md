# 湖理课表（HNIST Timetable）

仿 WakeUp / 超级课程表风格的 Android 课表 App，**只对接湖南理工学院教务系统**，
输入学号 + 统一身份认证密码即可一键导入本学期课表。

- 安装包：见本仓库 [Releases](../../releases)（正式版 v1.5.4，已签名，4.2 MB，Android 8.0+）
- 源码：`HNISTTimetable/`（Kotlin + Android View + Material 3，无第三方运行时依赖）
- 调试版 APK 多一个“载入示例课表”按钮（内置了一份示例数据，仅用于验证界面），日常使用请装正式版。

## 功能

| 功能 | 说明 |
| --- | --- |
| 一键导入 | 学号 + 密码 → 自动登录统一身份认证 → 进入教务系统 → 拉取课表 JSON → 解析保存 |
| 周视图 | 节次 × 星期网格，卡片按节次跨行，10 节次含上下课时间，今天所在列高亮；本周课程深色，非本周课程淡色占位 |
| 周次切换 | 课表或星期表头上左右滑动切换上/下一周；顶部周次条（当前周描边）可直接点选，自动定位到本周；菜单“回到本周” |
| 单双周 | 按教务系统的周次位图精确显示；非本周课程淡色占位（可在菜单关闭） |
| 课程详情 | 点击卡片：时间/周次/教师/校区·教学楼·教室/学分/考核方式/课序号 |
| 未排课程 | 没有固定时间的课（如实验课）单独列在课表下方 |
| 学期设置 | 开学日期自动从教务系统“第 N 周”结合手机当前日期推算（网页顶栏缓存的过期“星期几”不会影响结果），导入时算错的历史数据在打开 App 时自动对齐周一；也可手动修正，总周数可调 |
| 课表背景 | 菜单“更换课表背景”从手机相册选图：自动按课表比例居中裁剪、压缩后存在本机，铺在课表网格下面。“背景遮罩调节”用滑杆控制照片上白色遮罩的浓度（0% = 照片原样，100% = 纯白），拖动实时预览并记住；默认 60%。“恢复白色背景”一键清除。进行中的待办在课表下方全部铺开（无数量限制），按紧急程度从高到低排序 |
| 湖理网站 | 工具栏 🌐 进入内置浏览器：地址栏 + 常用入口（官网/统一认证/教务系统/本学期课表/信息中心）；页面按原始大小 1:1 显示、比屏幕宽就左右滑动，不缩放适配；网页自己禁止的横向滚动会被重新打开（页面根部 + 内容超宽却隐藏溢出的容器）；手机/电脑模式一键切换并记住（电脑模式固定按 1280px 电脑视口排版，得到电脑上的版面）；证书有问题时询问后可继续；window.open 弹窗在当前页打开；允许 http 页面、混合内容、跨站 Cookie；上传/下载/微信电话链接交给系统；打不开时给出原因并可切换模式或用系统浏览器打开；菜单可清除网站数据（退出登录） |
| 上课提醒 | 上课前 10/15/20/30/60 分钟发系统通知（课程、节次、时间、教室、教师），默认提前 20 分钟；菜单“上课提醒”可调或关闭，并显示下一次提醒时间 |
| 待办事项 | 工具栏 ☑ 进入：新增/编辑/勾选完成（先确认，防误触）/左滑删除（可撤销）/清除已完成；可设开始时间和截止日期，截止日还能指定当天几点截止（不设则当天全天有效），过了时刻立即按“已过期”变深红。到开始时间发通知；开始后未完成的待办会一直显示在课表主页下方，可直接勾选完成。未完成任务按剩余时间分级着色：>7 天灰、4–7 天琥珀、2–3 天橙、明天深橙、今天红、已过期深红（今天/明天/过期的标题也变色） |
| 日常任务 | 待办可设“每天”或“每周（选星期几）”重复，并可用“开始日期/截止日期”限定只在某段时间内重复（都不填则一直重复）：期间每天出现一次，勾选完成只算当天，第二天自动恢复。错过的一天不需要补做，但会中断连续天数并显示“错过 N 天”；连续天数按“上一次该出现的那天”计算（每周任务不会被中间不用做的日子打断）。设了开始时刻会到点提醒、开始后挂在课表下方；截止日过后自动结束 |

## 上课提醒是怎么工作的

- App 只在系统里挂**一个**闹钟，指向“下一节课开始时间 − 提前分钟数”；闹钟到点发通知后立刻计算再下一节。
- 打开 App、导入课表、修改学期设置、开机、系统时间改变时都会重算，所以关掉 App 也能收到提醒。
- Android 13 及以上首次进入课表页会请求通知权限；拒绝后可在系统设置里重新允许。
- 已声明 `USE_EXACT_ALARM`（课表属日历类用途），Android 13+/14 上无需去设置里开“精确闹钟”。
- 部分国产 ROM 会限制后台闹钟，若收不到提醒，请把“湖理课表”加入电池优化白名单/允许自启动。

## 导入流程说明

1. 在 App 中输入学号和统一身份认证密码，点“一键导入课表”。
2. App 内置网页会依次经过：`bkjw.hnist.cn` → 统一身份认证 `sso.hnist.edu.cn`（自动填表、点登录，密码由学校页面自己的 SM4 脚本加密）→ 门户 → 教务系统 `APP025` → 课表页。
3. 到达教务系统后，App 每 2 秒调用一次课表接口 `POST /student/courseSelect/thisSemesterCurriculum/ajaxStudentSchedule/callback`（最多 15 次），拿到合法 JSON 就解析 `classDay / classSessions / continuingSession / classWeek` 等字段并保存。不依赖页面上的任何文字（手机宽度下教务系统会隐藏顶栏的“欢迎您”“第 N 周”，v1.1.0 以前正是因为等这些文字而卡住）。
4. 导入期间网页占满屏幕，可上下滑动、双指缩放；如果学校页面弹出验证码、要求绑定手机或修改密码，直接在网页里手动完成，之后会自动继续。底部始终有“取消导入”，失败或等待超过 45 秒会出现“重新导入”；超过 3 分钟仍未完成会弹框让你选择“继续等待 / 重新导入 / 取消导入”，不会无限转圈。
5. 账号密码只发给学校统一身份认证；“记住密码”默认关闭，勾选后仅保存在本机。

## 如何构建

```powershell
./gradlew.bat assembleRelease            # 正式版（需 app/keystore.jks 签名，见下）
./gradlew.bat assembleDebug              # 调试版
./gradlew.bat :app:testReleaseUnitTest   # 单元测试（解析器用真实接口返回格式的数据验证）
```

首次运行 gradlew 会自动下载 Gradle 8.7；需要 JDK 17。`build.ps1` 是本机用的完整脚本：
先把源码镜像到 `D:\hnist_build\HNISTTimetable`（Android Gradle 插件不支持含中文的项目路径），
编译后把 APK 拷回本目录。正式版签名文件 `app/keystore.jks` 不上传，需要的同学自行生成并按
`app/build.gradle.kts` 里的 signingConfig 配置。

## 已知说明

- 只支持“本学期课表”接口；换学期后重新导入即可。
- 开学日期由导入当天教务系统显示的“第 N 周 星期 X”推算，若学校调整周次，可在“学期设置”里改。
- 本机 adb（32 位）因系统 Winsock 目录异常无法启动（`WSAStartup 11003`），不影响 App 本身；
  如需用 adb，可在管理员 PowerShell 执行 `netsh winsock reset` 后重启电脑。
